## 四、對研究設計的意義

1. **可以直接開始、不用新管線的**：注意股、處置股、當沖比、借券賣出流量。四種都已經有 2014 年起的資料，研究線的第一步可以先用它們做。
2. **事件行事曆可以建**：重大訊息（時間到秒）＋ 法說會 ＋ 月營收法定期限 ＋ 已有的除權息（`corporate_events`）。「只在事件前打分」的前提成立。
3. **論文裡最乾淨的兩個訊號，免費資料不夠用**：
   - 權證 IV 偏斜：沒有條款歷史，只能用成交比例當粗略替代，效果不保證接近論文。
   - 千張大戶：歷史只有 51 週。
   付費 FinMind 可以補千張大戶，權證條款的歷史則還沒找到任何來源。
4. 重大訊息約每天 300 則、2020 起約 1,600 個交易日，總共約 50 萬則主旨。只抓主旨、不抓全文的話，回補的量是可以接受的；抓全文要再估一次 MOPS 的頻率限制。
