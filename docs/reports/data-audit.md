## 檢查清單與其對應的真實缺陷

| 檢查 | 抓的是什麼 | 曾經漏掉它的原因 |
|---|---|---|
| 整腿缺席 | 某個分組（上市／上櫃／ETF）的佔比整段塌陷 | `sparse_dates` 以鄰近日為基準，停擺超過視窗時鄰居也全壞，一天都抓不到（T-136 的 61 天缺口即如此） |
| 稀疏日 | 短暫的列數塌陷 | 跨日重複偵測只找**多出來**的列，找不到少掉的 |
| 跨日重複快照 | 某天寫了別天的資料（含未來價格） | 擷取回報成功；只有比對 (close, volume) 完全相同才抓得到 |
| 個股列數斷層 | 缺口讓 `shift()` 的列位移跨越曆日缺口 | 標籤與因子都用列位移，跨過缺口的「20 日報酬」實際橫跨數月而**無任何標記** |
| 因子數／股票覆蓋率塌陷 | 缺表讓因子靜默消失 | `materialize` 逐因子 catch `DataError` 並只記 DEBUG，然後回報該日成功 |
| 非有限值 | 除以零的 inf | inf **不是** null，`drop_nulls` 放它過去；標籤含 inf 會被橫斷面平均擴散到當日所有樣本 |
| 橫斷面常數因子 | MAD=0 時 winsorize 把因子壓成常數 | 每一步都「正確」，合起來刪除因子，全程無錯誤 |
| 無市場別的股票 | 有行情但 `stock_meta.market` 為 null | `markets` 濾網**排除** null，缺 meta 的股票會無聲地離開宇宙——正是存活者偏誤的形狀 |
| 未還原的公司行動／零收盤價 | 分割與減資不在 `corporate_events` | 兩端都是正價，`_entry > 0` 與跨距防護都攔不住；0050 的 1:4 分割會變成 −74.8% 的單日報酬 |
