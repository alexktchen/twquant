# SPEC-012 — ML Phase 3：降周轉（延長持有 + buy/hold banding）

範圍：**只動組合構建層**。凍結 Phase 1 模型 `lgbm_h10_20260225_2f5a21a9`，
不重訓、不換特徵、不調 LightGBM、不改標籤。裁決見 D-041。

## 0. 這條路線的依據

Phase 1 判定失敗（D-038）的是**組合構建方式**，不是訊號。三項實測（見
`docs/HANDOFF-2026-08-31-ml-phase2-rootcause.md` §9，皆為零 trial 的唯讀診斷）：

| 事實 | 實測 |
|---|---|
| 訊號衰減 | **不衰減**：RankIC l=1 +0.0461 → l=10 +0.0680 → l=20 +0.0712 → **l=40 +0.0734（峰值）** |
| 實際持有 | **7.5 個交易日** |
| break-even 交易成本 | **0.420%**（台股實際 0.40–0.45%） |
| 單邊月周轉 | **239.5%**（門檻 <50%，超標 4.8×） |

即：**訊號是慢的（峰值 40 日），卻被以 7.5 日持有在交易**，
而 break-even 幾乎正好等於實際成本——這解釋了 0× 成本反事實為何只有 CAGR +1.23%。
分數的 lag-1 橫斷面 rank autocorr 為 **0.7397**；Qian/Sorensen/Hua 在
0.5%/100% 周轉成本（≈台股水準）下的淨最適 ρ_f 為 **0.93**。

文獻依據：Novy-Marx & Velikov（FAJ 2019）報告 banding
**在所有測試情境都降低交易成本且毛報酬無顯著下降**，小型股成本價差降 55%、
微型股降 77%；且 banding 勝過「降低再平衡頻率」（後者成本節省被毛報酬下降抵銷，淨值約 0）。

## 1. 候選定義（事前登記，不得搜尋）

單一候選，兩個**事前承諾的純量**，無網格搜尋：

- `entry_rank_pct >= 0.90`：分數落在當日橫斷面前 10% 才建倉。
- `exit_rank_pct < 0.70`：**已持有**部位僅在跌出前 30% 時出場。

其餘一律沿用 T-069 的既有設定：Top-20 等權、週一調倉、次日開盤成交、
相同成本模型、相同宇宙濾網、相同 participation 上限。
持有期的延長是 banding 的**結果**，不是另一個可調參數。

模型精確 pin `lgbm_h10_20260225_2f5a21a9`；分數讀 `serving.ml_scores`
（已存在 1,737,542 列，2022-01-14~2026-02-25），**不需要重新 backfill**。

## 2. 實作

`strategy/` 內新增純函數，輸入為當日 `rank_pct` 與前一日持股清單，
輸出目標持股清單：

```text
keep  = held ∧ (rank_pct >= exit_rank_pct)
enter = ¬held ∧ (rank_pct >= entry_rank_pct)
target = keep ∪ (enter 依 rank_pct 由高至低補足至 top_n)
```

- 參數放 `configs/strategies/ml_rank_band.yaml`，`.py` 內不得出現 0.90／0.70／20。
- 純函數、無 IO、無網路（黃金規則 10）；狀態由呼叫端（回測引擎）持有。
- 不得修改既有 `ml_rank.yaml` 的行為——T-069 的結果必須維持可重現。

## 3. 登記與評估

- trial scope 固定 `bt:ml_rank_h10_band`，與 `bt:ml_rank_h10` 分屬不同家族。
- **事前登記的方向性假設（一個主張，非四個獨立點）**：
  「在台股 0.40–0.45% 的成本水準下，加入 banding 後淨報酬優於無 banding 版本，
  且單邊月周轉下降。」
- **頭條指標改為兩個純量**（取代 OOS RankIC，Avramov 等人的中心指標）：

  | 指標 | 門檻 |
  |---|---|
  | break-even 交易成本 = 毛月頭尾價差 ÷ 單邊月周轉 | **> 0.60%** |
  | 單邊月周轉 | **< 50%** |

- 部署仍須同時滿足 D-038 §5 的既有成本後條件（CAGR > 0、Sharpe ≥ 0.5、
  MDD ≤ 30%、對最強線性基準 ΔSharpe ≥ 0.25、1.5× 成本後仍為正、
  四段至少三段正報酬、median fold Sharpe > 0、DSR ≥ 0.95）。
- 金庫期 2026-02-26~2026-08-28 **維持未開封**；本候選凍結前不得開啟。

## 4. 驗收條件

- AC-1：合成資料可手算——已持有且 `rank_pct` 介於 0.70~0.90 者**續抱**，
  未持有且同區間者**不建倉**；跌破 0.70 者出場。
- AC-2：`entry_rank_pct <= exit_rank_pct` 的配置載入即失敗（帶欄位名）。
- AC-3：banding 為純函數——相同輸入兩次呼叫輸出 bit-identical；
  無 `open(`、無 `write_parquet`、無 `import requests`（靜態閘門）。
- AC-4：同一段期間、同一模型，banding 版的**單邊周轉嚴格低於**無 banding 版。
- AC-5：`ml_rank.yaml` 的回測結果與 D-038 登記的
  `ff18453792d14cc4` 逐項相同（既有結果不得被本任務改動）。
- AC-6：診斷輸出含 break-even 交易成本與單邊月周轉兩個純量。
- AC-7：run 登記在唯一 `bt:ml_rank_h10_band` scope；完整品質閘門全綠。
