## 1. 問題與研究邊界

使用者確認研究「價量＋法人＋分點」，以籌碼改善而價格尚未反應的時間特徵預測後續發動。
每列為 `(signal_date, stock_id)`；推論只讀當時可用資料，輸出上漲事件分數。
機率未經樣本外校準檢查前，介面只能稱分數，不宣稱為可靠勝率。

- 本線暫名 `prelaunch_event_v1`，不替換既有模型、不修改生產選股。
- D-066 的 `lgbm_net_h20` 特徵、參數與研究禁令維持；標籤裁決（當時未建檔） 必須明定新事件研究的範圍。
  不能因標籤換成二元值，就推定已解除 D-066。
- D-074 的 F 模型預測營收驚奇，D-075 的 R 模型預測回撤；本線不能挪用其驗收結果。
- 股權分散先盤點，通過歷史／公布時間檢查後另登記增量實驗，不放入第一版。
- 這是可證偽的預測假說，不推論買盤真實身份或操縱意圖。

## 2. 標籤提案 A（建議，待 標籤裁決（當時未建檔））

以**收盤確認事件**避開日 OHLC 無法分辨高低點先後的問題：

1. 訊號截點沿用 `as_of_cutoff`（Asia/Taipei，20:00）；當日完整價量只在盤後使用。
2. 基準價為下一個市場交易日的個股開盤價。若當日無有效開盤，記 `entry_unavailable`，
   不順延到該股任意下一列；不得假裝已成交。
3. 觀察由入場日開始的 **20 個市場交易日收盤**（含入場日）。
4. 對基準持股的含息、分割調整後累積報酬，首次收盤達 **+0.10** 記上界事件，
   首次收盤達 **−0.05** 記下界事件。上界先到 `label=1`；下界先到 `label=0`；
   全窗完整但皆未到 `label=0, reason=timeout`。保存上下界日期和首達日數。
5. 即使提早到界，第一版仍統一在全觀察窗結束且來源可用後，才視為標籤成熟。
6. 尾端未成熟、期間缺價／停牌／下市、公司行動不完整分開記 reason，label 留 null，
   不編為「沒有上漲」。必須報告這些樣本占比與下市案例；資料缺陷交品質閘門，
   不可用 drop 掩蓋。若非隨機缺失使結果失去代表性，停止研究並另立裁決。

含息路徑以歷史持股公司行動帳務定義，禁止用未來調整因子修改當下的價格特徵。
成交可行性由獨立回測檢查：有開盤價格不等於能買到漲停股。
收盤到界後的策略成交須在下一個可成交時點，不使用剛觀察到的同一收盤价成交。

替代方案 B：以日內 high/low 觸界；同日雙觸須訂保守順序或補盤中資料。
A/B 不可同時跑完再挑較好者；改標籤構成新 trial，原結果保留。

## 3. 第一版特徵清單與真實語意

以下 14 個已有函數，**不等於物化資料已全期完整**；資料來源與公式以程式為準。

| 組 | 因子 | 用途／限制 |
|---|---|---|
| P | `price.mom_20d`, `price.mom_60d` | 近期位置與是否已漲一段 |
| P | `price.reversal_5d`, `price.vol_20d`, `price.high_52w` | 短期反轉、波動、長期價格位置 |
| V | `volume.vol_ratio_5d` | 今量／前期均量 |
| V | `volume.turnover_z_20d` | 程式用成交量時序 z，**不是真正流通股周轉率** |
| I | `chip.trust_net_10d`, `chip.foreign_net_10d` | 各法人累計淨買股數／同期成交股數 |
| I | `chip.trust_streak`, `chip.foreign_streak` | 已知歷史的連續買超天數 |
| B | `chip.broker_concentration_20d` | 清洗後主力淨買超占成交量的代理量 |
| B | `chip.broker_count_diff_5d` | 賣方分點數減買方分點數，再除以兩者和 |
| B | `chip.broker_persistence_10d` | 合計淨買超為正的日數比例，**不代表同一群分點持續買** |

不加入 `inst_net`，避免與外資／投信高度重複；不加入營收因子，使本輪能辨認籌碼增量。
既有因子 direction 是先驗標記，不強制買超、集中度或持續性對本模型單調正向。

時間／交互組 T 新增 8 欄，待裁決後實作：

- `delta_5` × 4：上述兩個法人淨買比例、分點集中度、分點持續性，當期 raw value
  減 **5 個市場交易日前訊號截點實際可知的 raw value**。
- `lag_5` × 2：上述兩個量能因子的五交易日前值。
- `flow_x_momentum` × 2：當期投信／外資淨買比例各乘當期 `price.mom_20d` raw value。

先計算 raw 衍生量，再標準化；不得把橫斷面 z 的變化誤稱真實買超變化。
缺少指定交易日快照則留 null 並記原因，不可用該股上一筆跨過缺日。
T 組是時間資訊的最小版本；「同一批分點」「首次放量距今天數」「分點領先網絡」
均列第二期，不冒稱 22 欄已涵蓋完整買盤身份與事件次序。

## 4. 資料與防前視

- 因子只經 `PitView`；PG 唯讀統計屬資料盤點，不是訓練特徵捷徑。
- 每個歷史特徵須按當日 cutoff 重建。`factor_values` 目前無 `available_at`，
  不可僅憑 date 就認定回補值當時可用，須核對來源／計算版本及資料指紋。
- 市場交易日曆對齊後才 rolling／lag；使用列位移前必須證明窗口無缺日。
- 時區 Asia/Taipei；stock_id 字串；成交量股、金額 TWD、報酬小數。
- 集保資料日不等於公布時點；第二期依 `available_at` backward asof join。
- 每月每因子列出有效 stock-days、缺值率、常數／inf、兩市場涵蓋率及最長缺口。
  公布延遲與資料修訂版本也須檢查，min/max 只表示端點，不代表中間完整。
- 全部比較共用當時宇宙與有效標籤樣本，不以今日存活股票清單建歷史宇宙。
  不因分點缺值而替不同模型偷偷改測試母體；資料斷層須先修復或事前限制共同期間。
- 全窗未到界者必須進入訓練與評估，禁止只回看後來的大漲股。

## 5. 固定比較、切分與停止條件（提案）

| Run | 模型 | 特徵 | 問題 |
|---|---|---|---|
| A | 邏輯迴歸 | P+V（7） | 簡單基準 |
| B | LightGBM binary | P+V（7） | 非線性本身的增量 |
| C | LightGBM binary | P+V+I（11） | 法人增量 C−B |
| D | LightGBM binary | P+V+I+B（14） | 分點增量 D−C |
| E | LightGBM binary | P+V+I+B+T（22） | 時間／交互增量 E−D |

Run 名稱 B 與特徵組 B（broker）分欄解讀。另列各訓練窗事件基準率常數預測，
不計為待調參模型。第一版只有以上 5 個固定候選，不搜尋窗口、門檻與超參數。

- 沿現有研究配置：首窗 2 年、測試 3 月、隔離 20 交易日、金庫 6 月，
  仍須逐列以 `label_available_at < fit_cutoff` 驗證成熟性，不能只信固定隔離天數。
  同一天所有股票置於同一分割。確定共同資料期間後才凍結實際日期。
- LightGBM 沿 `configs/ml_h20_cost_aware.yaml` 現有固定超參數；objective 改 binary。
  邏輯迴歸的正則化與實作依賴須在實作配置中寫定，不以 OOS 選參數。
- LightGBM 原生保留缺值；邏輯迴歸若需中位數插補、缺值指標與 scaling，
  只在訓練段 fit；全缺欄位拒絕訓練。插補方法須在配置與報告明示，禁止填 0。
- 主比較 E−B：OOS Brier score 改善的月度區塊 bootstrap 95% 信賴區間下界 > 0，
  且至少 60% 完整測試窗改善。未過停止，不改門檻重試；C−B／D−C／E−D 為歸因。
  Bootstrap 次數、seed、月份重抽規則於訓練前配置固定。
- 同報 average precision、基準事件率、每日前 10% 命中率／lift、校準分桶、各年／市場結果。
  全市場与 `mom_20d ∈ [−0.05, +0.05]` 事前分層都報；後者只代表低漲跌幅，
  不是完整箱型。不得看完結果才新增「有效情境」。
- 價格事件可預測不等於成本後可賺錢。預測閘門通過後，才以相同資金、持有／退出、
  宇宙、成本及成交模型比較 E 與 B 的經濟價值；先登記執行契約和經濟門檻，
  再開回測。主力／持股新增欄位另列 trial，不由 SHAP 值直接決定納入。
- 每次配置、失敗與消融都登記，不用新家族名稱歸零全專案的多重試驗歷史。
  金庫只在候選與規格定案後開一次；本輪不查標籤、績效或金庫內容。
