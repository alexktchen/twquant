## 二、你要做的申請（我不能代辦）

來源：[元大 SPARK API 首頁](https://www.yuanta.com.tw/file-repository/content/API/page/index.html)

1. **簽風險預告書**（首頁的步驟一）。有文章說證券要帶證件和印章臨櫃、約 5～10 個工作天；期貨的說法有線上也有臨櫃，**先打給營業員問清楚**。
2. **期貨權限要另外開**：證券帳號是 `S` 開頭、期貨帳號是 `F` 開頭，期貨要另外申請 API 權限。台指期一定要開這個。
3. **下載測試軟體跑測試、上傳結果**，再請營業員開通。
4. 測試環境（UAT）要請營業員幫你登記**固定 IP**才連得上；家裡如果是浮動 IP，要先問營業員怎麼處理。
5. 正式環境要用**正式憑證**（元大官網憑證專區申請）。
6. 順便問營業員：**行情能不能顯示在自己的網站上**（我們網站「小台模擬」「個股當沖」會顯示即時價）。元大文件沒寫轉傳規定；富邦是禁止轉傳，所以現在只給 admin 看。

## 三、電腦上要裝的東西

來源：[Python 設定](https://www.yuanta.com.tw/file-repository/content/sparkapi_docs/2.Python%E8%A8%AD%E5%AE%9A/Windows%E3%80%81Mac%E7%B3%BB%E7%B5%B1/index.html)

- **.NET SDK 8.0**（元件是 .NET 8 寫的）

- 跟富邦一樣放在 **repo 以外**的資料夾（例如 `C:\t\yuanta\`），不要讓 SDK 的 log 進 repo

登入（Windows）：`Open(PROD)` → `Login(帳號, 密碼)`，帳號密碼放 `.env`（例如 `YUANTA_ACCOUNT`、`YUANTA_PASSWORD`），不進程式碼。
來源：[登入](https://www.yuanta.com.tw/file-repository/content/sparkapi_docs/%E5%9F%BA%E7%A4%8E/%E7%99%BB%E5%85%A5/index.html)

## 四、要注意的使用限制

來源：[使用限制說明](https://www.yuanta.com.tw/file-repository/content/sparkapi_docs/1.%E5%89%8D%E8%A8%80/3.%E4%BD%BF%E7%94%A8%E9%99%90%E5%88%B6%E8%AA%AA%E6%98%8E/index.html)

- 一條連線最多訂 2,000 檔、一個帳號最多 3,000 檔；單次訂閱最多 200 檔、每秒最多訂 10 次
- 行情類查詢每秒 3 次、K 線每秒 1 次、整個帳號每分鐘 1,200 次
- **超量會停 1 分鐘；一小時內被停 10 次，帳號的 API 會被關掉** → 程式要自己節流，寧可慢
- 登入失敗每 4 秒才能再試一次；已登入不能重複登入

台指期現在訂 6 個合約＋3 個五檔，個股當沖的候選池遠低於 2,000 檔，數量都夠。

## 五、程式怎麼改（等拿到 SDK 再做）

現在富邦的部分其實集中在少數幾段：登入（`fubon_check.connect`）、WebSocket 訂閱與訊息解析、開盤後補抓（`backfill`）。
下游的模擬單、噪音區、盤口、上傳網站都只吃「時間、價、量、買價、賣價」和「五檔」，跟券商無關。

做法：

1. 新增 `yuanta_feed.py`：登入、訂閱逐筆與五檔、把元大的回呼轉成跟現在一樣的「時間（微秒）、價、量、買、賣」交給下游
   - 元大是 `OnResponse` 回呼（不是 WebSocket 文字訊息），時間欄位是時分秒＋毫秒，要自己組成當天的時間
   - 五檔沒有時間 → 用收到的當下時間
2. `fubon_live.py` → 改名 `futures_live.py`，把富邦那三段換成 `yuanta_feed`；原始訊息照樣存本機
3. `stock_live.py`（在 `research/ms-paper-trade` 分支）同樣換
4. `fubon_minute_download.py` → 改成只抓**個股**最近 20 天 1 分 K（台指期部分元大沒有，見第一段）
5. 網站上的說明文字、`source` 欄位從 `fubon_live` 改成 `yuanta_live`；`frontend/functions/_lib/futures.ts`、`daytrade.ts` 的提示字一起改
6. 拿掉富邦：`fubon_check.py`、`C:\t\fubon`、`.env` 裡的富邦帳密（你自己刪）

**不受影響**：`src/twquant/data/sources/fubon_chip.py` 是「富邦 DJ 網頁分點資料」爬蟲，跟富邦 API 無關，這次不動。
