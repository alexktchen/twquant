## 踩過的坑（下一輪別再踩）

1. **編輯執行中的 bash 腳本會弄壞它**——bash 會重讀檔案。本輪因此死掉兩批。
   一律跑快照副本 `.run_*.running.sh`。
2. **月頻模型的分數要 `--carry-forward-to`**，否則再平衡日撈不到任何列，
   池子整個空掉而**不會報錯**。
3. **`ml score` 寫的 `available_at` 是 `now`**（生產路徑正確）。
   事後補算歷史分數時必須改寫成**訊號日 19:00**，否則 PitView 在每一天都看不到自己的分數。
4. **`_ml_feature_frames` 要求該日所有特徵齊備**；籌碼類因子有 1~5 天的公布落差，
   所以最新一兩天可能推論不了（2026-09-08 就是空的）。
5. **模型 ID 會撞**：長窗口與短窗口的超參數相同，靠 `sample_tag`（lw／lwc）分開（T-172）。
6. **判準只看單一維度會誤判**（D-100：只看 ΔMDD 漏掉 8.9pp 的報酬差）。
